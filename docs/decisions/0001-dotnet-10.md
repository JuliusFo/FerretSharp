# ADR 0001: .NET 10 als Zielplattform

- Status: akzeptiert
- Datum: 2026-10-01

## Kontext

Der ursprüngliche Plan sah .NET 8 vor. Der Support für .NET 8 endet am 10.11.2026, also vor dem ersten Release.

## Entscheidung

- `FerretSharp.Core` und die Testprojekte zielen auf `net10.0`, die App auf `net10.0-windows`.
- SDK-Pinning per `global.json` (`10.0.400`, `rollForward: latestFeature`).
- Lösungsdatei im neuen Format `FerretSharp.slnx`, Paketversionen zentral in `Directory.Packages.props`.
- Tests laufen auf der **Microsoft Testing Platform** (xUnit v3 4.x setzt sie voraus; `global.json` → `test.runner`). Aufruf: `dotnet test` bzw. `dotnet test --project <pfad>`.
- Ein repo-lokales `nuget.config` beschränkt die Paketquellen auf nuget.org (Central Package Management verlangt sonst Package Source Mapping für global konfigurierte Zusatzquellen).

## Konsequenzen

- LTS-Support bis November 2028, C# 14 verfügbar.
- IDEs brauchen MTP-Unterstützung für die Testausführung (Rider und Visual Studio 2022 17.14+ haben sie).
